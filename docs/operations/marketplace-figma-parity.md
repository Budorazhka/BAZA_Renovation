# Marketplace Figma parity — scope and acceptance

Дата: 30.08.2026

Этот документ фиксирует, какие части большого Figma-файла относятся к публичному
маркетплейсу BAZA и какие изменения приняты в коде. Figma содержит также CRM,
кабинет риелтора, рейтинги и экспериментальные экраны; они не являются частью
публичного marketplace vertical и не переносятся в интерфейс автоматически.

## Выбранный продуктовый срез

В реализации учитываются только сценарии, которые существуют в текущем
marketplace и подтверждены локальным handoff в
`docs/discovery/figma-local-handoff.md`:

- главная с поиском и каталогом новостроек;
- каталог вторички и аренды, включая list/map view;
- карточка объекта и раскрытие контакта через lead flow;
- публикационный wizard для владельца объекта;
- общие шапка и подвал публичного каталога.

Экраны CRM, рейтингов, заявок и страницы, помеченные в Figma как `не
используется`, намеренно исключены. Это не потеря дизайна, а фильтр по
установленной концепции marketplace.

## Что выровнено в этом проходе

- catalogue-only floating controls больше не появляются на detail и publish
  routes;
- заголовок результата каталога снова виден пользователю и рядом показывает
  честный серверный total;
- footer стал полноценной общей поверхностью marketplace и остаётся доступным
  на публичных detail-страницах;
- display/body font families явно закреплены на карточках и ценах согласно UI
  kit (`Plus Jakarta Sans` и `Comfortaa`), с системным fallback;
- mobile-правила для заголовка каталога и footer складываются в одну колонку
  без горизонтального overflow;
- `theme-color` синхронизирован с основным зелёным токеном UI kit.

## Границы и проверяемые инварианты

- Backend, OpenAPI, DTO, фильтры, карта, SEO и lead semantics не меняются.
- Карточки используют только реальные данные публичного API; отсутствие media
  продолжает отображаться честным fallback.
- Floating controls доступны только на `/` и сохраняют текущие query-параметры
  при переключении list/map.
- Footer использует обычную навигацию приложения и не создаёт новые backend
  возможности.
- Разметка сохраняет landmarks, один `h1`, keyboard focus и mobile breakpoints,
  описанные в `frontend-marketplace-vertical.md`.

## Ограничение проверки

Прямой Figma MCP вызов в этой сессии упёрся в лимит Starter plan. Поэтому
реализация основана на переданном владельцем `.fig`-файле и зафиксированном
локальном handoff с node IDs и токенами, а не на догадках по произвольным
экранам. Полный browser smoke against live API должен быть выполнен в окружении
с установленными зависимостями; unit/jsdom-проверки добавлены для двух
изменённых route/layout invariants.
