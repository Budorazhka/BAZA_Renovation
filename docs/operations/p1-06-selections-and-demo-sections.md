# P1-06 — Подборки на сервере и честные незавершённые разделы

Дата: 07.09.2026. Статус: закрыто в рамках локального quality gate текущего workspace.

## Описание задачи и решений

1. **Безопасность и приватность подборок (Selections Backend)**:
   - Сохранено строгое разделение сессий и изоляция: приватный API подборок (`/selections`) доступен только авторизованным сотрудникам организации под защитой `TenantGuard` и `PermissionGuard`.
   - В публичной проекции (`PublicDevSelection` / `toPublicDevSelection`) исключено раскрытие приватных данных клиента: телефон клиента (`clientPhone`) удален из публичного ответа, предотвращая утечку персональных данных через ссылку на подборку.
   - В `DevSelectionRepository.markViewedByPublicToken`: добавлен фильтр `{ publicToken, status: { $ne: 'archived' } }`. Отозванные и архивированные подборки возвращают HTTP 404 `NotFoundException` при попытке открыть их по публичному токену.
   - HTTP integration spec `dev-selections.integration-spec.ts` дополнен проверками на отсутствие `clientPhone` в публичном ответе и возврат 404 для архивных подборок (10/10 тестов успешно).

2. **Персистентность подборок на витрине (`SelectionsPage`)**:
   - В `apps/marketplace-web/src/pages/SelectionsPage.tsx`: реализовано хранилище в `localStorage` по ключу `baza:marketplace:selections`.
   - Создание новых подборок, редактирование названий и удаление подборок синхронно сохраняются в браузере и не теряются при перезагрузке страницы.
   - Добавлены модульные тесты в `favoritesAndSelections.test.tsx`, подтверждающие создание, редактирование, сохранение в `localStorage` и удаление подборок (11/11 тестов успешно).

3. **Честные незавершённые разделы (Демонстрационный режим)**:
   - `RealtorsPage.tsx`: добавлен заметный информационный баннер `.demo-notice-banner` о демонстрационном статусе раздела рейтинга специалистов, карточки помечены бейджем «Демо-профиль».
   - `RealtorProfilePage.tsx`: добавлен баннер демонстрационного профиля и честное уведомление при отправке отзыва о сохранении в демо-режиме.
   - `RequestsPage.tsx`: добавлен баннер о демонстрационном режиме доски заявок и понятное уведомление при попытке создания заявки.
   - В `realtors.css` и `requests.css` добавлены стили для `.demo-notice-banner` и демо-бейджей.

## Поправка 11.09.2026

«Подборки на сервере» в заголовке относится только к CRM-подборкам агента
(`/selections`, в пределах организации). Подборки покупателя на витрине
(`SelectionsPage`) живут в `localStorage`, серверного backend для них нет. До
10.09 страница стартовала с выдуманных подборок `INITIAL_COLLECTIONS` («$85 000»,
Orbi City), и `localStorage` сохранял их как настоящие. Убраны в `f8b3afe`, список
по умолчанию пуст. Нужен ли серверный backend для подборок покупателя — вопрос
владельцу (roadmap, раздел решений).
