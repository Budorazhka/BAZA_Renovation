> **Статус**: Ожидает подтверждения владельца продукта перед началом написания UI-кода (Этап 3).

По правилам Figma Delivery Gate исполнитель **не имеет права додумывать или выбирать дизайн-решения**. Ниже собраны ровно 6 вопросов, требующих утверждения владельцем. Против каждого пункта зафиксированы точные числовые Node ID из Figma.

## Вопрос 1. Выбор версии Главной страницы (`/`) — Screen `MKT-SCR-001`
- **Родительская секция**: `1035:18100` (Canvas `0:1`).
- **Мобильный фрейм**: `1035:18101` (`mob_home`, 375x3461) — однозначный.
- **Проблема**: В Figma секции присутствуют 4 альтернативных десктопных фрейма:
  1. `1035:13357` (`Home page` v1, 1920x3566) — базовая композиция: Hero, категории, карусель ЖК, преимущества экосистемы;
  2. `1035:17004` (`Home page` v2, 1920x3346) — компактный промо-блок;
  3. `1035:17557` (`Home page` v3, 1920x3346) — альтернативная сетка карточек;
  4. `3428:55239` (`Home page` v4 long, 1920x5544) — расширенный макет с блоком сервисов, аналитики рынка и расширенным списком партнеров.
- **Вопрос владельцу**:
  > *Какую из 4 версий фрейма `Home page` (v1 `1035:13357`, v2 `1035:17004`, v3 `1035:17557`, v4 long `3428:55239`) утверждаем как базовый источник для десктопной Главной страницы?*

## Вопрос 6. Унификация отсутствующих состояний (DoD / System States)
- **Проблема**: В Figma отсутствуют отрисованные экраны:
  - Loading skeleton для каталога и карточек;
  - Empty state (0 результатов поиска/фильтрации);
  - Служебные страницы ошибок 404 / 500 (`MKT-SCR-027`);
  - Модальное окно входа/регистрации (`MKT-SCR-013`).
- **Предложение**: Реализовать данные состояния системно в строгом соответствии с UI kit Canvas `40:4517` (шрифты Comfortaa / Plus Jakarta Sans, основной цвет `#169600`, цвет ошибки `#c83227`, фон ошибки `#fdf2f2`, радиус скругления 10px, компоненты кнопок `29:4695`, инпутов `4687:62204`).
- **Вопрос владельцу**:
  > *Утверждаем ли системную реализацию отсутствующих состояний по правилам и токенам UI kit без ожидания отдельной отрисовки дизайнером?*
