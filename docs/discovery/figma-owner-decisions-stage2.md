## Решение 5. Скоуп публичных профилей застройщика и агентства (`MKT-SCR-025`, `MKT-SCR-026`)
- **Решение**: **Исключить создание отдельных страниц профилей из MVP первой волны**.
- **Обоснование решения**:
  - В Figma макеты данных экранов отсутствуют полностью (в отличие от прорисованного профиля риэлтора `3576:53737`).
  - На действующем сайте `baza.sale` отдельных страниц застройщиков также нет: клик по логотипу/имени застройщика фильтрует каталог новостроек (`/newconstructions?developer=...`).
  - Поведение реализуется через фильтрацию каталога без выдумывания несуществующего UI.
- **Статус**: **УТВЕРЖДЕНО**.

## Решение 6. Системные состояния (Loading, Empty, Error 404/500)
- **Решение**: **Реализовать недостающие состояния системно по токенам UI kit Canvas `40:4517`**.
- **Спецификация реализации**:
  - **Skeletons**: анимированные серые заглушки (`background: #eef2eb`, shimmer effect) строго по габаритам карточек `card ЖК` (`4747:74437`, радиус 10px) и карточек списка.
  - **Empty states**: центрированный блок с иконкой, текстом Comfortaa 16px (`#555454`) и кнопкой сброса фильтров (`#169600`, радиус 10px).
  - **Error 404 / 500**: системные экраны с токенами `--color-error: #c83227` и `--color-error-bg: #fdf2f2`, кнопка возврата на главную.
- **Статус**: **УТВЕРЖДЕНО**.
