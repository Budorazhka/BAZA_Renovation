# UI Contract: Final TZ

Источник истины: `Pred Tz Baza Sale Detailed.docx.md`.

Этот файл фиксирует frontend-контракт для реализации без кастомизации:
- фиксированные роли;
- фиксированные наборы виджетов по ролям;
- единая навигация по модулям;
- desktop-only.

## 1) Роли (рабочий контур)

Используются роли:
- `owner` — Собственник агентства
- `director` — Директор агентства
- `rop` — Руководитель отдела продаж
- `manager` — Менеджер по продажам / риелтор
- `marketer` — Маркетолог
- `procurement_head` — Специалист по закупке объектов
- `administrator` — Администратор агентства / операционный администратор
- `trainee` — Стажёр
- `lawyer` — Юрист
- `finance` — Финансовый руководитель

Условные роли мастер-направлений — только заглушки на UI-уровне.

## 2) Модули (панели)

Поддерживаются панели из финального ТЗ:
- CRM классическая
- CRM модная (внешняя ссылка)
- Документы
- Лиды: источники и распределение
- Объекты, комиссии и партнёры первичного рынка
- Брони
- Регистрация клиента у застройщика
- Объекты вторичного рынка
- MLS вторичного рынка
- MLS аренда
- Команда
- Обучение и база знаний
- Финансы
- Сообщество
- Автозадачи, триггеры и уведомления
- Настройки системы

## 3) CRM модная

`CRM модная` открывается внешней ссылкой:
- `https://crm.baza.sale/`

`CRM классическая` — внутренний контур приложения.

## 4) Виджеты

Используются строго фиксированные наборы из раздела 7.5 ТЗ:
- без пользовательской кастомизации;
- без drag-and-drop;
- без скрытых пользовательских настроек набора.

## 5) Правило доступа

Недоступное по роли:
- не отображается в меню;
- не отображается в виджетах/хабах;
- не должно появляться в навигации для роли.

## 6) Desktop-only

Поддерживается только desktop-режим.
Mobile/tablet адаптация в scope не входит.
