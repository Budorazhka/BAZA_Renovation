# Спецификация тегов CRM заметок

Все HTML/Markdown теги которые бэкенд шлёт в поле `notes` лида CRM.

---

## 1. Заголовки

| Тег | Описание | Пример |
|-----|----------|--------|
| `# ЗАГОЛОВОК` | Главный заголовок клиента (КАПС) | `# 🎯 КЛИЕНТ: МАРИЯ` |
| `## Подзаголовок` | Заголовок секции (используется в fallback) | `## 📍 География` |

---

## 2. Цитаты

| Тег | Описание | Пример |
|-----|----------|--------|
| `> Текст` | Саммари клиента (выделяется на фоне) | `> Мария ищет квартиру в Батуми` |

---

## 3. Жирный текст

| Тег | Описание | Пример |
|-----|----------|--------|
| `**текст**` | Ключевые значения | `- **Бюджет:** $120,000` |

---

## 4. Списки

| Тег | Описание | Пример |
|-----|----------|--------|
| `- элемент` | Маркированный список | `- **Город:** Тбилиси` |

---

## 5. Таблицы

| Тег | Описание | Пример |
|-----|----------|--------|
| `| Заголовок | Значение |` | Шапка таблицы | `| **💰 Бюджет** | $120K |` |
| `|----------|----------|` | Разделитель | `|----------|----------|` |
| `| Ячейка 1 | Ячейка 2 |` | Строка таблицы | `| Тип | Квартира |` |

---

## 6. Раскрывающиеся секции (HTML)

| Тег | Описание | Пример |
|-----|----------|--------|
| `<details>` | Контейнер раскрывающейся секции | `<details>...</details>` |
| `<summary>` | Заголовок секции (кликается) | `<summary>📍 География</summary>` |

**Пример использования:**
```html
<details>
<summary>📍 География</summary>

- **Страна:** Грузия
- **Город:** Батуми

</details>
```

---

## 7. Горизонтальная линия

| Тег | Описание | Пример |
|-----|----------|--------|
| `---` | Разделитель между секциями | `---` |

---

## 8. Визуальные индикаторы (текстовые)

| Паттерн | Описание | Пример |
|---------|----------|--------|
| `████░░░░░░` | Бар прогресса (10 символов) | `🌡️ Температура: ████████░░ **75/100**` |
| `emoji` | Эмодзи-маркеры | `🎯 📍 💰 📊 ⚠️ ✅ ➡️` |

---

## 9. Эмодзи-маркеры секций

| Эмодзи | Секция |
|--------|--------|
| `🎯` | Клиент, Рекомендации |
| `👤` | Данные лида |
| `📍` | География |
| `💰` | Финансы |
| `📈` | Инвестиционный профиль |
| `🏠` | Желаемый объект |
| `⚠️` | Возражения, Риски |
| `👥` | Лица решения |
| `💬` | Коммуникация |
| `📊` | Скоринги |
| `🤝` | Доверие |
| `📋` | Юридическая готовность |
| `🔍` | Профиль подбора, Качество данных |
| `✅` | Подтверждённые факты |
| `➡️` | Следующие шаги |
| `📝` | Параметры клиента |
| `📱` | Телефон из чата |
| `❌` | Отказ |

---

## 10. Скоринг-бары

| Метрика | Формат |
|---------|--------|
| Температура | `🌡️ Температура: [bar] **[value]/100**` |
| Вероятность | `🎲 Вероятность: [bar] **[value]%**` |
| Качество | `⭐ Качество лида: **[value]/100**` |
| Зрелость | `📊 Зрелость: **[text]**` |
| Риск ухода | `🚨 Риск ухода: **[value]/100**` |

**Генерация бара:**
```
'█'.repeat(Math.round(value / 10)) + '░'.repeat(10 - Math.round(value / 10))
```

---

## 11. Полный пример

```html
# 🎯 КЛИЕНТ: МАРИЯ

> Мария ищет квартиру в Батуми для переезда с семьей.

| Параметр | Значение |
|----------|----------|
| **💰 Бюджет** | $120,000 |
| **📍 Локация** | Батуми, Грузия |

---

<details>
<summary>📍 География</summary>

- **Страна:** Грузия
- **Город:** Батуми
- **Район:** Центр

</details>

---

<details>
<summary>📊 Скоринги</summary>

🌡️ Температура: ████████░░ **75/100**
🎲 Вероятность: ██████░░░░ **60%**

</details>
```

## 12. Фронт: поддержка

| Библиотека | Нужно | Что добавить |
|------------|-------|--------------|
| react-markdown | Да | `rehype-raw` плагин |
| dangerouslySetInnerHTML | Нет | HTML уже рендерится |
| Plain text | Да | Переключить на react-markdown |

**CSS для `<details>`:**
```css
details { margin: 6px 0; border: 1px solid rgba(255,255,255,0.08); border-radius: 8px; }
details summary { cursor: pointer; font-weight: 600; padding: 10px 12px; }
details summary::before { content: '▸'; margin-right: 8px; transition: transform 0.2s; }
details[open] summary::before { transform: rotate(90deg); }
details[open] { background: rgba(255,255,255,0.02); }
```
