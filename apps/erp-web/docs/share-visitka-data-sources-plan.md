# План: куда добавляем источники данных для визитки

Цель — закрыть свитчеры с ❌ реальными источниками. Часть на старте остаётся хардкодом в коде, потом переезжает в данные.

Источники делятся на 5 мест:
- **A. Справочник городов и стран** — общий (бэк/админка), переиспользуется всеми ЖК. Не на фронте.
- **B. Визард новостроек** — поля конкретного ЖК (per-project).
- **C. Профиль застройщика / настройки** — данные компании-застройщика.
- **D. Хардкод в коде** — статичные блоки, ок оставить.
- **E. Уже есть** — трогать не надо.

---

## A. Справочник городов и стран (общий, на бэке)

Ключ связи: `project.city` / `project.country` → запись справочника. Один раз заполнили город/страну — работает для всех ЖК в нём.

| Свитчер | Что добавить | На старте |
|---|---|---|
| Информация о городе | `city.text` (описание города) | хардкод-пресеты в коде → потом справочник |
| Галерея города | `city.gallery[]` (реальные фото) | сток-заглушка → справочник |
| Информация о стране | `country.text` / инвест-преимущества | хардкод (Грузия) → справочник |
| Галерея страны | `country.gallery[]` | сток-заглушка → справочник |
| Арендный потенциал | `city.rentalText` / `country.rentalText` | хардкод (Батуми/Грузия) → справочник |

> Это то, про что ты писал «предусмотреть не на уровне фронта». Сейчас тексты Батуми/Грузия и сток-фото зашиты в коде — это Phase 0. Phase 1 — вынести в справочник с админкой.

## B. Визард новостроек (поля ЖК)

| Свитчер | Что добавить | Куда в визарде |
|---|---|---|
| Документы | `project.documents[]` (загрузка файлов / ссылок) | шаг «Застройщик и документы» |
| Галерея района | `project.districtGallery[]` (реальные фото района) | шаг «Инфраструктура» или новый «Район» |
| Информация о районе | `project.districtText` — **только если нужны тексты** | опц., шаг «Инфраструктура» |

> Сейчас «Информация о районе» собирается из адреса + инфраструктуры (этого может хватать). Пространных текстов про район нет — добавлять `districtText` только если они реально нужны.

## Решения (зафиксировано)

| Свитчер / поле | Куда зашиваем форму | Детали |
|---|---|---|
| Логотип компании | **Настройки** — новое поле «Логотип компании» | приписка: «PNG, прозрачный фон» |
| Документы | **Визард ЖК**, привязка к ЖК | загрузка PDF (разрешения на строительство, договоры и пр.), клиенту показываем напрямую |
| Информация о районе | — | собираем из того, что есть (адрес + инфраструктура), отдельного поля не добавляем |
| Галерея района | **Визард ЖК** (per-project) | загрузка фото района |
| Аренда / инвест-цифры | **Визард ЖК**, заполняет менеджер застройщика | per-project текст + проценты, не хардкод |
| Город / страна (текст + галерея) | **Справочник** (на бэке) | тексты Батуми/Грузия пока хардкод как пресет (Phase 0) |
| Как проходит покупка · Связаться с нами | — | остаются статикой в коде |

Языки контента — **все три** (ru / en / ka) обязательны.

## Порядок работ

1. **Phase 0 (сейчас, хардкод в коде):** пресеты текстов город/страна/аренда + сток-фото — уже частично есть. Привести к единому виду, чтобы потом легко вынести.
2. **Phase 1 — Справочник городов и стран (A):** модель на бэке + админка (текст + галерея + аренда), визитка читает по `city`/`country`. Закрывает 5 свитчеров разом.
3. **Phase 2 — Визард (B):** документы ЖК + галерея района (+ опц. текст района).
4. **Phase 3 — Застройщик (C):** логотип и описание компании в настройках.
